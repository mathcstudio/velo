# 위치의 변화량과 움직인 거리

고등학교 2학년 미적분Ⅰ 「정적분의 활용 – 속도와 거리」를 한 차시(50분) 동안 학생이 태블릿으로 혼자 공부하는 웹앱입니다. 평균 이하 학생을 대상으로 만들었습니다. 계산은 최소로 줄이고, **그래프 넓이 → 식 계산** 순서로 진행합니다.

- 화면: 깃허브 페이지 (`index.html`)
- 서버: 구글 앱스크립트 (`Code.gs`)
- 기록: 구글 스프레드시트

## 학습 흐름

학생은 학번 5자리와 이름으로 입장합니다(비밀번호 없음). 단계마다 **개념 배우기(설명 화면)** 를 먼저 넘겨 봐야 문제가 열립니다.

| 단계 | 개념 배우기 | 문제 (묶음마다 하나 골라 풀기) |
|---|---|---|
| 1단계 · 왜 배울까? | 집 → 편의점 → 집 왕복 애니메이션 (위치의 변화량 0 m, 움직인 거리 600 m) | 갔다가 돌아오는 점 / 위치의 변화량이 음수인 버스 |
| 2단계 · 미분과 적분의 관계 | 위치 →(미분)→ 속도, 정적분 = 부정적분의 차이 | **빈칸 채우기**: 교과서 자율 주행 버스 `x=12t−3t²` → 적분상수 C가 사라지는 이유 |
| 3단계 · 속도를 적분하면 위치의 변화량 | 직사각형 넓이 → 삼각형 넓이 → 음의 속도(아래쪽 넓이는 뺀다) | 그래프 넓이로(계단 그래프 / **출발점이 0이 아닌 문제**) → 식으로 계산(교과서 문제 1 / 제자리로 돌아오는 점) |
| 4단계 · \|속도\|를 적분하면 움직인 거리 | 01 넓이 단원 `∫|f(x)|dx` 복습과 연결, 위치의 변화량과 움직인 거리 비교, 3단계 방법(멈춘 순간 찾기 → 구간 나누기 → 모두 양수로 더하기) | 그래프 넓이로(방향을 바꾸는 점 / 교과서 예제 2 쏘아 올린 공) → 식으로 계산(교과서 예제 1 / 문제 2) |
| 마지막 확인 | — | 단계마다 공책에 적은 핵심 정리를 빈칸으로 다시 쓰기 |
| 보너스(선택) | — | 교과서 문제 4 주행 로봇, 돌아오는 점 |

- **움직임 그림**: 설명 화면에서 ▶를 누르면 속도–시간 그래프의 넓이(앞으로 간 만큼 파랑, 뒤로 간 만큼 주황)가 차오르면서, 수직선 위의 점이 함께 움직입니다. 위치, 위치의 변화량, 움직인 거리 값이 실시간으로 바뀝니다. 막대를 밀어 원하는 시각에서 멈춰 볼 수도 있습니다.
- **용어**: 교과서 용어(위치의 변화량, 움직인 거리)만 씁니다.
- **입력**: 화면 숫자판으로 입력합니다. 분수(`23/3`)와 음수를 받으며, 약분하지 않아도 값이 같으면 정답입니다.
- **틀렸을 때**: 정답은 알려 주지 않습니다. 먼저 학생이 낸 오답에 맞는 안내(예: "그것은 움직인 거리입니다. 위치의 변화량은 처음과 나중만 봅니다.")가 나오고, 이어서 스스로 점검할 질문이 나옵니다. 힌트는 버튼을 눌러야 보입니다.
- **감점 없음**: 틀린 횟수는 기록만 합니다. 한 줄에서 기회(선택형 3번, 입력형 5번)를 다 쓰면 그 문제만 처음부터 다시 풉니다. 이때 숫자가 바뀐 같은 유형의 문제가 나옵니다.
- **학생마다 다른 숫자**: 몇몇 문제는 학번에 따라 숫자가 달라서 옆 사람 답을 그대로 옮겨 쓸 수 없습니다. 같은 학생은 어느 기기에서 들어와도 같은 숫자를 봅니다. 설정에서 끌 수 있습니다.
- **분량**: 반드시 풀어야 하는 문제는 7개(1+2+2+2), 개념 설명은 13장입니다. 보통 학생 기준 35~40분이 걸리고, 남는 10분은 교사 정리 시간으로 잡았습니다. 시간이 모자라면 2단계의 적분상수 문제를 수업 중에 함께 풀어도 됩니다.

## 관리자 모드(교사용 화면)

첫 화면 아래 **관리자 모드**에 `설정` 시트의 비밀번호를 넣고 들어갑니다.

- **학급별 × 단계별 통과율**: 학급은 학번 둘째·셋째 자리로 나눕니다(20101 → 2학년 1반).
- **학급 명단**: 학생별 통과한 단계, 총점, 자주 보인 오개념을 보여 줍니다. 선택하거나 전체를 삭제할 수 있습니다.
- **오개념 유형**: 학생이 고르거나 입력한 오답을 착각의 종류별로 모아, 그 착각을 보인 학생 수 순으로 보여 줍니다.
  - 위치와 위치의 변화량 혼동
  - 위치의 변화량과 움직인 거리 혼동
  - 음의 속도(뒤로 간 것)를 처리하지 못함
  - 속도가 0인 순간을 못 찾음
  - 구간을 나누지 않음
  - 처음 위치를 빠뜨림
  - 빼는 순서를 거꾸로 함
  - 미분과 적분의 방향 혼동
  - 정적분 = 부정적분의 차이를 적용하지 못함
  - 계산 실수
  - 삼각형 넓이에서 ½을 빠뜨림
- **문항별 오답률**: 많이 틀린 줄과 가장 많이 고른 오답을 함께 보여 줍니다.

다음 시간 도입에서 **오개념 유형 표의 위쪽 두세 개**를 다루는 것을 권합니다.

## 설치

### 1. 서버 (구글 스프레드시트)

1. 새 구글 스프레드시트를 만들고 [확장 프로그램] → [Apps Script]를 엽니다.
2. `Code.gs` 내용을 모두 지우고 이 저장소의 `Code.gs`를 붙여 넣은 뒤 저장합니다.
3. 스프레드시트를 새로고침한 뒤 [속도와 거리] → [처음 설정]을 실행합니다(권한 승인 필요).
4. `설정` 시트에 **관리자 비밀번호**를 입력합니다.
5. [배포] → [새 배포] → 유형 **웹 앱**으로 배포합니다. 실행 계정은 '나', 액세스 권한은 **'모든 사용자'**로 정합니다. 로그인이 필요한 권한이면 깃허브 페이지에서 호출이 막힙니다.
6. 나온 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 복사합니다.

> `Code.gs`를 고친 뒤에는 [배포] → [배포 관리] → 연필 → 버전 '새 버전'으로 **다시 배포**해야 반영됩니다. 주소는 바뀌지 않습니다.
> 학교 구글 계정에서 '모든 사용자'를 고를 수 없으면 개인 계정으로 만들어야 합니다.

### 2. 화면 (깃허브 페이지)

1. `config.js`의 따옴표 안에 서버 주소를 붙여 넣고 커밋합니다.
2. 저장소 [Settings] → [Pages]에서 Source를 'Deploy from a branch', Branch를 `main` / `(root)`로 정합니다.
3. `https://<계정>.github.io/<저장소>/` 주소를 학생에게 나눠 줍니다.

`config.js`의 주소를 비워 두면 서버 없이 화면만 동작합니다. 이때 기록은 그 기기에만 남고, 관리자 모드에는 예시 데이터가 나옵니다. 미리 보기용으로 쓰세요.

### 3. 수업 전 확인

학생 기기 한 대로 **입장 → 1단계 문제 하나 → 시트에 기록됨**까지 직접 확인하세요. 교사가 직접 풀어 본 시간의 2~2.5배가 보통 학생이 걸리는 시간입니다.

## 알아 둘 점

- **본인 확인이 없습니다.** 다른 학번으로 입장할 수 있으므로 성적 근거로 쓰지 말고 형성평가와 활동 기록용으로 쓰세요.
- 같은 학번에 다른 이름으로 들어오면 "이 학번으로 다른 이름의 기록이 이미 있습니다"라는 경고가 한 번 나옵니다. 다른 학생의 이름은 보여 주지 않습니다.
- 학번, 이름, 풀이가 스프레드시트에 저장됩니다. 학교 개인정보 지침을 확인하세요. 화면 코드(깃허브)에는 개인정보와 비밀번호가 들어가지 않습니다.
- 선택형·입력형 정답은 화면 코드 안에 들어 있습니다. 코드를 뜯어보는 학생은 정답을 볼 수 있습니다.
- 서버 주소는 `config.js`에 공개됩니다. 수업이 끝나면 [배포 관리]에서 배포를 보관 처리해 닫아 두면 안전합니다.
- 개념당 문제는 한두 개입니다. 확인 수준이지 숙달은 아닙니다. 남은 문제와 보너스는 과제로 쓰세요.

