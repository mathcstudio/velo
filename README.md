# 🪄 VELO — 태블릿 바이브코딩 교실

학생이 정해진 프롬프트 형식으로 원하는 앱을 설명하면 GPT가 웹앱을 만들어 줍니다.
학생은 그 앱을 **고치고 → 버그를 잡고 → 배포**해서 친구들과 나누는 과정까지 체험합니다.

- **설치 안내(교사용):** [docs/SETUP.md](docs/SETUP.md)
- 구조: Next.js (Vercel) + Supabase + OpenAI API

## 학습 흐름

| 단계 | 학생 활동 | 화면 |
|---|---|---|
| ① 기획 | **V·I·B·E 카드**로 첫 프롬프트 쓰기 | 프롬프트 카드, 완성도 게이지 |
| ② 생성 | AI가 코드를 쓰는 모습을 실시간으로 보고, 완성된 앱 실행 | 스트리밍 코드, 미리보기 |
| ③ 수정 | **바꿀 곳 → 바꿀 내용 → 그대로 둘 것**으로 고치기, 버그 신고, 버전 비교, 되돌리기 | 고치기, 버그, 자유 모드, 기록 탭 |
| ④ 배포 | 체크리스트 통과 → (교사 승인) → 주소와 QR로 공개 → 갤러리에서 좋아요와 피드백 | 배포 탭, 갤러리 |

### 프롬프트 형식

**처음 만들기: V·I·B·E**
- **V** 무엇을: 어떤 앱이고 누가 쓰나요?
- **I** 어떻게 작동: 무엇을 누르면 어떤 일이 일어나나요?
- **B** 모습: 색, 글씨, 분위기
- **E** 조건: 꼭 지킬 규칙과 예외 상황

**고치기:** 바꿀 곳 → 바꿀 내용 → 그대로 둘 것

**버그 고치기:** 내가 한 행동 → 기대한 결과 → 실제 결과 (+ 브라우저가 자동으로 잡은 오류)

## 주요 기능

**학생**
- 학급 코드, 이름, PIN 4자리로 로그인 (이메일 불필요)
- 예시 칩, 음성 입력(🎤), 프롬프트 완성도 게이지, AI에게 보낼 프롬프트 미리 보기
- 생성 중 코드 스트리밍 표시, AI의 변경 요약
- 앱 오류 자동 감지 → 원클릭으로 버그 고치기
- 버전 타임라인, 예전 버전 보기, 지금 버전과 나란히 비교, 되돌리기
- 코드 보기, 전체 화면
- 배포 체크리스트, 공개 주소(`/p/xxxxxx`), QR 코드
- 우리 반 갤러리: 좋아요, 피드백

**교사 (`/teacher`)**
- 반 만들기, 학급 코드를 칠판에 크게 띄우기
- 학생별 오늘 사용량, 사용 중지, PIN 초기화
- 학생별 **프롬프트 기록**(평가·세특 자료), 버전 실행해 보기, 차단된 입력 확인
- 배포 승인과 반려, 공개 앱 숨기기
- AI 켜기/끄기, 모델, 1인당 하루·분당 호출 한도, 추가 지시문
- 오늘 호출 수와 토큰 사용량

## 안전장치

| 위험 | 대책 |
|---|---|
| API 키 유출 | 키는 Vercel 서버 환경변수에만 둠. 브라우저는 VELO 서버만 호출 |
| DB 직접 접근 | 모든 테이블에 RLS를 켜고 정책 없음 → 공개 키로는 접근 불가. 서버만 service_role 키 사용 |
| 학생 앱 코드가 사이트를 공격 | 미리보기는 `sandbox` iframe(다른 출처), 배포 주소는 `CSP sandbox` 헤더로 다른 출처 처리. 외부 접속(`connect-src 'none'`) 차단 |
| 부적절한 입력 | 프롬프트, 앱 이름, 피드백을 OpenAI Moderation API로 검사. 차단 기록은 교사 화면에 표시 |
| 비용 폭주 | 1인당 하루·분당 한도, 동시 생성 1개, AI 전체 끄기 스위치 |
| 혼잡(OpenAI 429) | 학생 화면에서 안내 후 자동 재시도(최대 3회, 점점 길게 대기). 혼잡으로 실패한 호출은 한도에서 빼 줌 |

## 개발

```bash
npm install
cp .env.example .env.local   # 값 채우기
npm run dev
```

폴더 구조:

```
app/
  page.tsx              학생 로그인
  studio/               내 앱 목록, 작업실(/studio/[id])
  gallery/              우리 반 갤러리
  teacher/              교사 관리 화면
  p/[slug]/route.ts     배포된 학생 앱 (공개 주소)
  api/                  서버 API (generate = AI 호출)
components/             화면 컴포넌트
lib/
  prompts.ts            프롬프트 카드 정의, 형식, 미리보기 보안 설정
  openai.ts             시스템 프롬프트, OpenAI 스트리밍, 결과 파싱, 검열
  session.ts / auth.ts  로그인 쿠키, PIN 해시, 권한 확인
supabase/schema.sql     DB 구조 (SQL Editor에서 한 번 실행)
```

AI에게 주는 규칙(시스템 프롬프트)은 `lib/openai.ts`의 `systemPrompt()`에 있습니다.
